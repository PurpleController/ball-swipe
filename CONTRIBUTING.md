# Contributing

Thanks for wanting to contribute to Ball Blast!

## Reporting Bugs

Please include:

* Godot version
* Operating system
* Steps to reproduce the issue

## Pull Requests

Before making changes:

* Keep code readable
* Test your changes
* Explain what was changed

## AI Policy

If your code is AI-generated:

* State that it was AI-generated
* State which AI model was used
* Do not submit fully AI-generated features or large sections of code without reviewing and understanding them

## Development

Ball Blast is made with Godot.

## How to Contribute

1. Fork this repository
2. Make any changes you want
3. Commit your changes
4. Open a Pull Request to the PRs branch

Pull requests may be reviewed before being merged into the project.
